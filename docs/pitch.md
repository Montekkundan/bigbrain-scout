# Two-minute pitch outline

**BigBrain Scout — inspect before you fetch, record what you received.**

**0:00–0:25 · User problem.** A high-resolution ROI request carries assumptions about coordinate space, scale, bounds and resource use. Researchers need those assumptions to be visible and the returned data to remain traceable.

**0:25–0:55 · The proposed tool.** Scout checks available scales and bounded requests before downloading, shows decoded-byte and chunk-allocation estimates, then compares requested versus returned metadata. It saves a capsule containing data, preview, manifest and checksum.

**0:55–1:25 · Two-day goal.** One tiny real cell-body-stained section patch, one clear blocked unsafe request, one requested-versus-returned report and one independently reviewed provenance example. Some older siibra reports appear to be fixed; this is a workflow project, not a claim that those bugs persist.

**1:25–1:50 · Join us.** We need Python/testing, visualization, neuroscience metadata review and documentation. The offline foundation is prepared; the useful user interface and domain checks are team work.

**1:50–2:00 · Close.** “Inspect before you fetch. Record what you actually received.” Show the public repository and contributor issues.

## Suggested one-slide contents

Title; the three-step line **Request → Preflight → Verified capsule**; one small requested-versus-returned example labelled illustrative; four contributor roles; repository URL. Avoid slides asserting unverified defects, guaranteed memory safety, anatomical correctness or independent reproduction that has not been tested.
