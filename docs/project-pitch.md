### Project title

BigBrain Scout — safe, reproducible high-resolution ROI extraction

### Short description and goals

Build a small user-facing preflight and provenance workflow for bounded, high-resolution BigBrain ROI requests. Before fetching, make the reference space, available scale, ROI bounds and estimated decoded/chunk sizes explicit. After fetching, compare requested and returned metadata and preserve data, preview, source information and checksum in a reproducibility capsule.

Two-day MVP: one tiny cell-body-stained section patch, one clearly blocked unsafe request, a requested-versus-returned report, and a reviewed capsule example. A dependency-free synthetic starter is prepared; visualization, domain review, broader testing and independent live reproduction remain team work. Historical siibra issue discussions motivate the checks, but some reported bugs have maintainer fixes and are not claimed as current independently reproduced defects.
